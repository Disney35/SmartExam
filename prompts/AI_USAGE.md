# AI Assistance During Development

## Why I Used AI Tools

I used AI tools as a development assistant while working on SmartExam.

Since this project involves several modules and scheduling rules, AI assistance helped me understand requirements, plan the application and troubleshoot issues during development.

I did not treat AI-generated suggestions as automatically correct. I used them as a starting point and checked the implementation by running the application and testing the APIs.

## Areas Where AI Helped

### 1. Project Planning

I used AI assistance to understand the project requirements and decide how to divide the application into modules.

This helped me plan the student, course, enrollment, examination, room and invigilator modules.

### 2. Backend Development

I used AI suggestions while developing Spring Boot entities, repositories, services and REST controllers.

I also used the suggestions to understand relationships between database tables.

### 3. Scheduling Logic

I used AI assistance to understand how to check room capacity, room availability, invigilator availability, student examination conflicts and student accommodations.

I reviewed the scheduling responses and tested different situations using Postman.

### 4. Database and Configuration

AI assistance helped me troubleshoot PostgreSQL connection settings, application configuration and Spring Boot startup issues.

### 5. Sample Data Generation

I used AI assistance while developing the Python data generator.

The generator uses a fixed seed to create repeatable sample records and includes a separate file describing known test scenarios.

### 6. Debugging and Documentation

I used AI suggestions to investigate errors, understand API responses and prepare project documentation.

## How I Checked the Work

I checked the application by:

- Starting the Spring Boot backend.
- Connecting the application to PostgreSQL.
- Creating and retrieving sample records.
- Testing REST APIs using Postman.
- Running the Python data generator.
- Checking the generator's validation summary.
- Running the generator again to check whether its outputs were reproducible.

## My Responsibility

AI tools helped me during development, but I am responsible for the final project.

I need to understand the code, verify the scheduling rules and be able to explain the decisions made in the application.
